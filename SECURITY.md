# Security policy

## Reporting a vulnerability in wormsign

Please use [GitHub private vulnerability reporting](https://github.com/nukoe-labs/wormsign/security/advisories/new).
Do not open a public issue. You will get an answer within 3 working days.

Examples: a crafted repository that makes wormsign crash, hang, or hide a finding; a token leaked in the output.

## Reporting an infected repository

wormsign does not collect reports of infected repositories. If you find one:

1. Warn its owner, without publishing any secret you may see (for example a token in a commit message).
2. Report it to GitHub: https://github.com/contact/report-abuse (category "Malware or phishing").

## Supported versions

Only the latest release receives fixes.
